# SmartHome 智能家居系统

> STM32 + ESP32 双 MCU 架构 · FreeRTOS 多任务 · MQTT 物联网云端控制
> 独立完成的全流程自研项目（硬件搭建 → 驱动开发 → RTOS 架构 → 云端联调）

## 📱 项目简介

基于 **STM32F103C8T6 + ESP32-S3** 双 MCU 架构的智能家居系统：STM32 负责本地传感器采集与设备控制，ESP32 负责 WiFi/MQTT 云端通信，通过 UART 桥接实现**本地控制与云端解耦**——断网时本地自动控制仍正常工作。

可通过手机（巴法云小程序/App）远程查看温湿度、光照数据，并远程控制灯光、门（舵机）、风扇（电机）。

## ✨ 功能特性

| 功能 | 实现方式 |
|------|----------|
| 温湿度监测 | DHT11 单总线传感器 |
| 光照检测 | 光敏电阻 + ADC |
| LED / RGB 彩灯 | 按键手动 + 光照自动联动 |
| 门（舵机 SG90） | 按键 / 云端控制 |
| 风扇（TB6612 电机） | PWM 调速，光照阈值自动联动 |
| 蜂鸣器报警 | 温度 >35°C 自动触发 |
| OLED 显示 | 实时显示全部状态 |
| 手机远程控制 | ESP32 + 巴法云 MQTT |

## 🔌 硬件接线（STM32F103C8T6）

| 功能 | 引脚 | 说明 |
|------|------|------|
| DHT11 | PA0 | 单总线，需 4.7K 上拉 |
| 光敏电阻 | PA1 | ADC1_CH1，0-4095 |
| KEY1~KEY4 | PA2~PA5 | 输入上拉（灯/风扇/门/模式） |
| 舵机 SG90 | PA6 | TIM3_CH1 PWM 50Hz |
| 风扇 PWM | PA7 | TIM3_CH2 |
| USART1 TX/RX | PA9/PA10 | ↔ ESP32 GPIO16/17，115200 |
| LED / RGB | PB5 / PB6,7,15 | RGB 共阳低电平亮 |
| OLED (I2C) | PB8/PB9 | 0.96寸 |
| TB6612 AIN1/AIN2 | PB12/PB13 | 电机方向 |
| 蜂鸣器 | PB14 | 高电平触发 |

> ⚠️ 舵机/电机必须**外部 5V 供电**（STM32 电流不足）；ESP32 单独 USB 供电，注意共地。

### ESP32-S3 接线

| ESP32 | STM32 |
|-------|-------|
| GPIO17 (TX2) | PA10 (RX) |
| GPIO16 (RX2) | PA9 (TX) |
| GND | GND（必须共地） |

## 🧵 FreeRTOS 任务架构

| 任务 | 优先级 | 栈(字) | 职责 |
|------|--------|--------|------|
| SensorTask | 2 | 256 | 采集 DHT11 温湿度 + 光照 ADC |
| ControlTask | 2 | 256 | 按键扫描、模式切换、设备控制 |
| DisplayTask | 1 | 256 | OLED 状态刷新 |
| AlarmTask | 1 | 128 | 温度超限蜂鸣器报警 |
| UartTask | 1 | 256 | 与 ESP32 通信（协议解析） |

**同步机制**：`dataMutex` 互斥锁保护共享数据 `data_t`；按键中断通过二值信号量 `keySem` 唤醒 ControlTask；DisplayTask 先拷贝数据再释放锁刷新（缩短持锁时间）。

## ☁️ MQTT 云端链路（巴法云）

- **上报**：ESP32 采集传感器数据 → publish 到 `smarthome_data` 主题
- **下发**：手机端发布指令 → ESP32 订阅 `smarthome_led/fan/door` 主题 → UART 转发 STM32
- **协议**：`T:25.6,L:2048,LED:ON,FAN:OFF,DOOR:OFF`（STM32→ESP32 上报）/ `LED:ON\n`（ESP32→STM32 指令）

巴法云配置：注册 [bemfa.com](https://bemfa.com) → 获取私钥 → 创建主题 → 微信小程序绑定。

## 🐛 踩坑记录（真实开发经验）

1. **DHT11 读取失败**：缺 4.7K 上拉电阻 → 补齐后正常
2. **舵机不转**：STM32 电流不足 → 舵机改外部 5V 供电并共地
3. **多任务数据冲突**：OLED 乱码/偶发死机 → 互斥锁保护共享数据
4. **按键不灵敏**：轮询消抖不可靠 → 改 GPIO 中断 + 信号量
5. **OLED 刷新卡顿**：DisplayTask 持锁太久（I2C 慢）→ 先拷贝数据再释放锁刷新
