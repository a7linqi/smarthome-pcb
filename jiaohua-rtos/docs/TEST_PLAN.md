# 联合调试清单

按顺序测试。前一步不通过，不进入下一步。

1. **静态检查**：确认安装 DRV8833；水泵暂不接；STM32、ESP8266 共地；串口 TX/RX 交叉。
2. **STM32 启动**：烧录后 OLED 正常刷新，按键可切换页面，系统持续运行 5 分钟不复位。
3. **传感器**：DHT11 每约 2 秒更新；土壤 ADC 随干湿变化；记录真实干土和湿土 ADC。
4. **手动控制**：手动 ON 时 PB14 约 3.3 V，OFF 时约 0 V；DRV8833 BO1/BO2 出现接近 VM 的差分电压。
5. **保护功能**：水泵连续开启 30 秒后自动关闭并显示报警；重新切换模式后才能解除锁定。
6. **Wi-Fi/MQTT**：OLED 显示 MQTT OK；断开路由器后显示离线；恢复网络后约 5～10 秒内重新上线。
7. **数据上报**：MQTT 客户端订阅数据主题，每约 2 秒收到一次温度、湿度、土壤、水泵和报警信息。
8. **远程控制**：在手动模式发布水泵 ON/OFF 命令，检查 PB14 和水泵动作；自动模式下远程强制开泵应被控制策略拒绝。
9. **长时间运行**：连续运行至少 2 小时，观察是否重启、OLED 卡死、MQTT 失联或水泵异常启动。

测试时保留串口日志、MQTT 消息截图和整机视频，这些是简历项目可验证的证据。
